About

Gerolamo is a lightweight, modular Cardano node/relay implementation in TypeScript. This tool bootstraps UTxO state from Mithril LMDB snapshots into IndexedDB for browser-based node operation.

Pipeline: LMDB snapshot → Bun FFI → NDJSON stream → Browser fetch → IndexedDB → Query & Analytics
